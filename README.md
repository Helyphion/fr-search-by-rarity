## Flight Rising Search By Rarity

### What is this?
If you've ever wanted to make a breeding pair with genes of equal rarities, but didn't feel like manually selecting them all from the dropdowns, this is for you!


### Usage Tips
- Sections without any boxes checked are not added to the search filter, so leaving them empty is functionally identical to selecting every option.
- Use the trashcan icon to clear all boxes in a section at once!
